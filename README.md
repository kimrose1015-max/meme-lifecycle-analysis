# 검색량 기반 밈의 생애주기 분석 및 연구

**Google Trends의 웹·유튜브 검색량으로 밈의 생성과 소멸을 분석하고, 초기 검색 패턴을 이용해 단기·장기 유행을 분류한 R 기반 데이터 분석 프로젝트입니다.**

- **수행 배경:** 2025학년도 1학기 수업 팀 프로젝트(원본 폴더명: 데프기실)
- **팀원:** 김윤지(데이터사이언스전공), 이병현(멀티미디어공학과)
- **기술:** R, readr, dplyr, stringr, lubridate, ggplot2, randomForest
- **자료:** Google Trends 대한민국 웹 검색·유튜브 검색 시계열, 주기 분석 CSV, 예측 결과, 발표자료

## 프로젝트에서 다룬 질문

1. 검색량을 이용해 밈의 시작과 소멸을 어떻게 정의할 수 있을까?
2. 같은 밈도 웹과 유튜브에서 유행하는 속도와 지속 기간이 다를까?
3. 검색량이 정점에 도달한 뒤 감소하는 패턴으로 단기·장기 유행을 구분할 수 있을까?

## 분석 흐름

```mermaid
flowchart LR
    A[Google Trends 검색량] --> B[생성·소멸 및 지속 기간 분석]
    B --> C[6개월 기준 단기·장기 분류]
    C --> D[웹·유튜브 공통 밈 비교]
    D --> E[평균 검색량 곡선 비교]
    E --> F[피크 이후 하락률 기반 분류]
    F --> G[기존 주기 분류와 결과 비교]
```

발표에서는 검색량이 전체 최댓값의 15% 이상으로 일정 기간 유지되는 구간을 시작으로 보고, 15% 미만으로 유지되는 구간을 소멸로 정의했습니다. 유효 구간에는 최댓값의 80%에 도달하는 피크가 있어야 합니다. 지속 기간이 **6개월 미만이면 단기**, **6개월 이상이면 장기**로 구분했습니다. 소멸일이 없는 밈은 당시 분석 기준일로 기간을 계산했습니다.

## 주요 관찰과 결과

- 발표에서는 공통 단기 밈 **36개**, 공통 장기 밈 **38개**를 대상으로 플랫폼별 평균 곡선을 비교했습니다.
- 분석 표본에서 웹은 유튜브보다 초기 반응이 빠르고, 유튜브의 단기 밈은 급등락이 더 뚜렷한 경향을 관찰했습니다.
- 첫 번째 피크 이후 하락 양상이 단기·장기 밈을 구분하는 단서라고 해석했습니다.

| 구분 | 발표 당시 보고 내용 | 현재 보존 상태 |
| --- | --- | --- |
| 규칙 기반 분류 | 하락률 65%, 분류 가능 비율 70.5%, 분류 가능한 표본의 정확도 74.1% | 발표 PDF에 기록; 동일 결과 재현 미확인 |
| 랜덤포레스트 분류 | 정확도 71%, 단기 57개·장기 43개 | 발표 PDF에 기록; 해당 분류 학습 코드·모델 파일 없음 |
| 추가 생존기간 회귀 | 첫 30개 검색량으로 총 생존개월수 학습 | 제공 R 원본과 실행용 정리본 추가; 위 분류 성능과 별개 |
| 보존된 R 코드 | 하락률 50%를 기준으로 분류 | 원본 TXT 및 경로를 정리한 실행 스크립트 제공 |

**발표 수치와 저장된 CSV는 서로 다른 분석 상태를 담고 있습니다.** `병합.csv`에서 실제·예측 유형이 모두 단기/장기인 48개 중 일치하는 것은 25개(52.1%)입니다. 이를 발표의 74.1%와 동일한 실험 결과로 취급하지 않습니다. 자세한 차이는 [분석 방법과 한계](docs/methodology.md), [자료 안내](docs/data-guide.md)를 참고하세요.

## 실행 방법

저장소 루트에서 R 4.4.3 기준으로 실행합니다.

```bash
Rscript scripts/install_packages.R
Rscript scripts/classify_memes.R
# 입력 폴더, 출력 CSV, 하락률 임계값을 지정할 수도 있습니다.
Rscript scripts/classify_memes.R data/raw/web-analysis results/generated/predictions-65.csv 0.65
# 당시 CSV 결과의 표본 수와 일치율 확인 (Python 표준 라이브러리)
python3 scripts/audit_results.py
```

기본 임계값은 원본 코드와 같은 **0.50**입니다. 0.65 실행은 발표 기준을 참고한 비교 실행이며, 발표 결과를 재현했다고 의미하지 않습니다. 생성 파일은 `results/generated/`에 저장됩니다.

추가로 제공된 R 코드를 바탕으로 밈 여부 판별과 생존기간 회귀도 실행할 수 있습니다.

```bash
Rscript scripts/screen_memes.R
Rscript scripts/train_survival_regression.R
Rscript tests/test_trends_io.R
```

기본 웹 자료 78개에서 판별 코드는 오류 없이 실행됐고, 회귀 코드는 주기 자료 100행 중 77행으로 학습됐습니다. 회귀의 내부 OOB 설명 분산은 약 **-2.64%**로 예측력을 뒷받침하지 못했습니다. 첫 30개 **관측치**는 유행 시작 이후에 정렬한 값이 아니며, 달력상 소멸일 예측도 아닙니다. 원본별 구현 범위와 수정 내용은 [추가 R 코드 안내](docs/additional-r-analysis.md)를 참고하세요.

## 재현 범위

보존된 R 규칙 기반 분류 코드와 추가 제공된 밈 여부 판별·생존기간 회귀 코드를 실행할 수 있도록 경로와 입력 처리를 정리했습니다. 추가된 `머신러닝 및 예측.R`는 `find_meme_periods()` 정의가 빠져 있어 생애주기 추출 전체를 재현할 수 없습니다. 평균 곡선 생성 코드와 발표의 랜덤포레스트 **분류** 학습 코드·모델도 확인되지 않았습니다. 발표의 전체 분석을 한 번에 재현하는 파이프라인은 아닙니다.

원본 CSV는 월별 자료인데 코드에는 일부 구간이 주 단위로 주석 처리되어 있습니다. 전체 시계열의 최댓값을 참조하므로 실시간 예측 성능으로 해석하기 어렵고, 별도 테스트셋 성능도 확인되지 않았습니다.
