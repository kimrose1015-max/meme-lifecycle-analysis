# 추가 R 코드: 밈 판별과 생존기간 회귀

추가로 제공된 R 파일 3개를 검토하고 원본 보존본과 실행용 정리본으로 나누었습니다. 파일 제목만으로 구현 범위를 판단하지 않고 실제 코드에서 확인되는 동작을 기록합니다.

## 원본과 실행용 코드

| 제공 파일 | 확인된 동작 | 저장소 반영 |
| --- | --- | --- |
| `밈_시작소멸판단.R` | 검색량 15 이상인 관측치가 1개 이상이면 밈으로 판별 | 원본 보존 + `scripts/screen_memes.R` |
| `머신러닝 및 예측.R` | CSV를 정리해 `find_meme_periods()`를 호출하고 시작·소멸일을 모으는 배치 처리 | 원본 보존; 함수 정의가 없어 독립 실행 불가 |
| `밈 소멸예측.R` | 검색량 벡터로 총 생존개월수를 학습하는 랜덤포레스트 회귀 | 원본 보존 + `scripts/train_survival_regression.R` |

원본은 [`archive/r-scripts`](../archive/r-scripts)에 수정 없이 보존했습니다. `rm(list=ls())`, 사용자 절대경로, `View()` 등도 원본에는 남아 있습니다. 실행용 코드에서는 저장소 상대경로·명령행 인자를 사용하고 필요한 처리만 분리했습니다.

`머신러닝 및 예측.R`에는 모델 학습이 없고, 핵심 `find_meme_periods()` 구현도 없습니다. 이 함수의 규칙을 임의로 채워 넣지 않았으므로 생애주기 추출 전체의 재현 범위는 여전히 제한됩니다.

## 밈 여부 판별

```bash
Rscript scripts/screen_memes.R
Rscript scripts/screen_memes.R data/raw/web-analysis results/generated/meme-screening.csv
```

- 원본 조건은 `검색량 >= 15`인 관측치가 하나 이상인지 확인하는 것입니다.
- 결과 열은 `file`, `qualifying_observations`, `is_meme`, `status`입니다.
- 월별 입력에서는 조건 충족 횟수도 월별 관측치 수입니다. 원본 변수명에 있는 “일수”로 해석하지 않습니다.
- 시작일·소멸일을 추출하거나 연속 유지 구간·80% 피크 조건을 검증하지 않습니다.
- Google Trends의 상대 관심도는 각 시계열에서 정규화되므로, 15 이상 관측치 존재만으로 밈 여부를 타당하게 검증했다고 볼 수 없습니다. 실제 기본 입력 78개는 모두 이 조건을 충족했습니다.

## 생존기간 회귀

```bash
Rscript scripts/install_packages.R
Rscript scripts/train_survival_regression.R
# 시계열 폴더, 주기 CSV, 출력 폴더를 순서대로 지정할 수 있습니다.
Rscript scripts/train_survival_regression.R data/raw/web-analysis data/processed/밈_웹_주기.csv results/generated/survival-regression
```

입력 주기 CSV는 `file`(또는 `파일명`), `start`, `end` 열을 사용합니다. 날짜는 저장소의 `YYYY-MM`과 `YYYY-MM-DD`, 원본 코드가 의도한 영문 `Jun-25` 같은 형식을 지원합니다. 두 자리 연도는 2000년대로 해석합니다. 월만 있는 날짜는 해당 월 1일로 변환합니다.

| 항목 | 구현 |
| --- | --- |
| 입력 특성 | 각 CSV의 첫 30개 검색량, `V1`~`V30`; 부족하면 뒤에 0을 채움 |
| 목표값 | `floor((end - start)의 일수 / 30)` |
| 모델 | `randomForest`, 회귀, 트리 200개, `set.seed(123)` |
| 제외 조건 | 시작/소멸일 누락·해석 불가, 역전된 날짜, 대응 CSV 없음, 입력 오류 |
| 파일명 연결 | Unicode NFC 정규화 후 일치; 임의의 유사 이름 연결 없음 |
| 저장 | `survival_regression.rds`, `training-data.csv`, `skipped.csv` |

원본의 미정의 `data_dir`, 누락된 `randomForest` 로딩, 실제 CSV의 `file` 열과 코드의 `파일명` 열 차이, 날짜 형식 불일치를 정리했습니다. 학습행이 너무 적거나 목표값에 변동이 없으면 중단합니다. 제외 사유는 `skipped.csv`로 확인할 수 있습니다.

이 코드는 **총 생존기간 회귀**입니다. 단기·장기 이진 분류나 달력상의 소멸일·현재부터의 잔여기간 예측은 구현하지 않습니다. 새 CSV를 받아 예측하는 별도 명령도 포함하지 않습니다.

## 공통 입력 처리의 변경

`scripts/lib/trends_io.R`에서 날짜 행을 찾아 메타데이터 길이가 다른 CSV를 읽습니다. UTF-8과 CP949를 지원하고, `<1`은 기존 실행 스크립트와 일치하도록 0으로 처리합니다. 이는 숫자 이외 문자를 제거해 `<1`을 1로 바꾸던 제공 코드와 다릅니다. 잘못된 값, 0~100 범위 밖 값, 중복·역순 날짜는 오류로 기록하거나 제외합니다. 임시 `~$` 파일은 제외합니다. 원본 CSV는 수정하지 않습니다.

## 실제 실행 확인

2026-11-26, R 4.4.3 / `randomForest` 4.7-1.2 / `stringi` 1.8.7에서 저장소의 기본 입력으로 확인했습니다.

- 밈 판별: CSV 78개 처리, 입력 오류 0개, 조건 충족 78개.
- 회귀: 주기 자료 100행 중 77행 학습, 시작/소멸일 누락·해석 불가 22행 및 대응 CSV 없음 1행 제외. 상세 사유는 실행 시 생성되는 `skipped.csv`에서 확인합니다.
- 이 실행의 내부 OOB 평균제곱오차는 약 **196.45**, 설명 분산은 약 **-2.64%**였습니다. 성능을 뒷받침하는 결과가 아니며 독립 테스트셋 평가도 아닙니다.
- 공통 입력 처리 점검: `Rscript tests/test_trends_io.R`.

생성 결과는 `.gitignore`의 `results/generated/` 아래에 저장합니다. 학습 모델은 실행으로 생성하며 원본 모델을 복원한 파일로 취급하지 않습니다.

## 해석의 한계

첫 30개 값은 **유행 시작 이후가 아니라 CSV 첫 행부터의 관측치**입니다. 기본 자료는 월별이며 다수 파일은 2004년부터 시작합니다. 따라서 이를 “초기 유행 30일의 특징”으로 설명할 수 없고, 유행 이전의 긴 구간이 학습될 수 있습니다. 짧은 입력의 0 채움도 실제 검색량 0과 구분되지 않습니다.

목표값의 30일 나눗셈은 달력상 개월 차이와 다릅니다. 소멸하지 않은 밈은 제외되므로 장기 지속 사례가 학습에서 빠지는 편향이 있습니다. 독립 검증 분할, 교차검증, 튜닝 및 소멸일 예측 검증도 구현되어 있지 않습니다.

발표에 기록된 **랜덤포레스트 분류 정확도 71%**는 이번 총 생존기간 회귀 코드로 재현하거나 검증한 값이 아닙니다. 원본 분류 학습 코드·모델은 여전히 확인되지 않았습니다.
